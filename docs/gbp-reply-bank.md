# Approved auto-reply bank

For 4-5 star reviews that clear every routing check in `gbp-voice.md`.
Chris approves this list ONCE; nothing outside it is ever auto-posted.

`{name}` is the reviewer's first name only. If the profile has no usable
first name, use the variant with no placeholder.

## With a name
1. Thanks {name}, we look forward to seeing you again
2. Thanks {name}, we appreciate the support
3. Thanks for the support {name}, come see us again soon
4. Glad you enjoyed it {name}, see you next time

## Without a name
5. Thanks for your support!
6. Thanks for supporting CJ's Funtime rental, look forward to seeing you again
7. We appreciate the support, look forward to the next rental
8. Glad you had a good time, see you next time

## Rules
- Rotate least-recently-used so the profile never shows the same line twice
  in a row.
- 6 is Chris's own words, verbatim. 5 likewise. Keep both.
- Nothing here restates the review, describes the reviewer, apologises,
  promises anything, or links anywhere.
- Adding a line means adding it here and getting Chris's okay. The poster
  reads this file and nothing else.
